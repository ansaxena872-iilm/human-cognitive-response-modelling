# human-cognitive-response-modelling
A webcam-based prototype for analysing observable human behavioural responses to visual stimuli using computer vision and computational modelling.
Human Cognitive Response Modelling:
A computer vision project exploring observable human behavioural responses to visual stimuli using webcam-based facial feature tracking and computational modelling.

Objectives:
Capture facial data using a webcam.
Present controlled visual stimuli.
Record observable facial movements and response times.
Analyse and visualise behavioural patterns.

Technologies:
Java
OpenCV for Java
JavaFX
Maven (optional)

Project Status:
Prototype development in progress.
