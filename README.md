
# Human Cognitive Response Modelling

A Java-based computer vision prototype exploring observable human behavioural responses to visual stimuli using webcam-based facial feature tracking and computational analysis.

## Objectives

- Capture video using a webcam.
- Present controlled visual stimuli, such as a rose and neutral objects.
- Extract measurable facial features.
- Record response timing and behavioural observations.
- Visualise and analyse response patterns.

## Planned Technology Stack

- Java 21
- OpenCV for Java
- Maven for dependency management
- JavaFX for the desktop interface

## Planned Modules

1. Webcam capture
2. Stimulus presentation
3. Facial feature tracking
4. Behavioural response logging
5. Results visualisation and CSV export

## Project Status

Initial project setup. Prototype implementation and validation are in progress.

## Privacy

Participant recording requires informed consent. Raw recordings and identifiable participant data should not be committed to a public repository.
